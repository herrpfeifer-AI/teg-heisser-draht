# Heisser Draht

Lern-App zu Stromkreisen für das Werken-Projekt «Heisser Draht» (5. Klasse).
Statische Seite (index.html, js/) + eine Vercel-Funktion (api/api.js, Neon Postgres, Tabelle lw_kv).

- Kinder: 4-stelliger Code (Lehrerbereich → Klasse → Kärtchen drucken)
- Einfach üben (ohne Login): /einfach
- Lehrerbereich: /lehrer (Passwort = Umgebungsvariable TEACHER_PASSWORD)
- Speicher: DATABASE_URL (Neon) im Vercel-Projekt «lichtwaechter»
